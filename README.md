# 星泉聲音工坊

完全以繁體中文星泉程式撰寫的跨平台音訊示範，同一份編譯成果可執行於桌面與瀏覽器。

八個琴鍵展示音調生成及同時混音；旋律由星泉事件迴圈逐個觸發；低音展示循環播放；原創提示音展示封裝音檔載入。音量、左右聲像與音高可即時切換。下方顯示共用音訊引擎實際產生的四四〇赫茲 PCM 波形。

## 建置與執行

先在相鄰的 `AquariusLangTW` 專案建置含音訊功能的編譯器及桌面執行環境，再執行：

```powershell
./建置.ps1
# 也可指定正式版編譯器：
./建置.ps1 -編譯器 'C:/星泉/aqua.exe'
# 只輸出 Wasm 與網站：
./建置.ps1 -略過桌面
```

桌面開啟 `dist/星泉聲音工坊.exe`。網站可在本資料夾執行 `node 網頁伺服器.mjs`，然後開啟顯示的 localhost 網址。以檔案網址開啟網站無法使用音訊工作執行緒。

點琴鍵或按數字鍵一至八彈奏；空白鍵停止所有聲音。首次播放若出現「開啟音訊」，請點選以符合瀏覽器的自動播放規則。左右聲像建議使用耳機。示範啟動時保持靜音，點選後才開啟即時輸出。

`音訊驗證.aqua` 可在沒有音訊硬體時驗證音調、樣本、暫停、停止、循環及音檔解碼，建置腳本會先執行此驗證。`中文介面.aqua` 集中星泉既有繪圖協定的名稱，沿用其他繁體中文示範專案的慣例；所有函式宣告、呼叫、變數、註解及使用者介面都使用繁體中文。

音色資料夾內的提示音由此專案產生，採用與專案相同的 MIT 授權。生成式音調、WAV、FLAC 與 MP3 的解碼及混音在所有平台共用 miniaudio WebAssembly；實際音量仍受系統設定與喇叭影響。
